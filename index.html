Tutorial

ধাপে ধাপে অ্যাপ ব্যবহার

ডানের ফোনের স্ক্রিনে দেখুন আসল অ্যাপের প্রতিটি অংশ — ধাপে ট্যাপ করলেই স্ক্রিন সেখানে চলে যাবে।

  1. সার্চ বার, সাম্প্রতিক ফাইল, ছবি-ভিডিও-অডিও-ডকুমেন্টের ক্যাটাগরি আর আপনার Telegram Cloud — সবকিছু এক স্ক্রিনেই।

    নিচের ডানদিকের New বাটন দিয়ে নতুন কিছু যোগ করুন।

  2. Settings → Backup থেকে Auto Backup অন করুন। Target Folders-এ বেছে নিন কোন ফোল্ডার ব্যাকআপ হবে, আর Wi-Fi Only অন রাখলে মোবাইল ডাটা খরচ হবে না। এখনই সিংক করতে চাইলে Sync Now চাপুন।

    সতর্কতা: Auto-Delete from Phone অন থাকলে ব্যাকআপ হওয়া ফাইল ফোন থেকে মুছে যেতে পারে — চালু করার আগে একবার নিশ্চিত হয়ে নিন।

  3. Cloud Usage-এ দেখুন ক্লাউডে কতটা জায়গা ব্যবহার হয়েছে। Local Cache, Cache Limit আর Cache Duration দিয়ে ঠিক করুন ফোনে ক্যাশ কতটা জায়গা নেবে এবং কতদিন থাকবে।

  4. App PIN Lock চালু করে ৪ সংখ্যার PIN দিন; পরে Change App PIN থেকে বদলানো যায়। অ্যাপ কিছুক্ষণ ব্যাকগ্রাউন্ডে থাকলে আবার লক হয়ে যায়।

    Biometric Unlock অপশনও এখানেই আছে।

  5. Dark Theme অন-অফ করুন, Accent Color বদলে অ্যাপের রঙ বেছে নিন। Auto-Load Thumbnails আর ফাইল সেভ করার Save Location-ও এখান থেকেই ঠিক হয়।

  6. App Update-এ ট্যাপ করলে নতুন ভার্সন আছে কিনা দেখে নেয়; থাকলে অ্যাপের ভেতর থেকেই ডাউনলোড ও ইনস্টল করা যায়। অ্যাকাউন্ট বদলাতে চাইলে Log Out ব্যবহার করুন।
